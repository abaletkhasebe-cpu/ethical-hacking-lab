# Ethical Hacking Lab 🔐

A comprehensive, interactive platform for learning cybersecurity and ethical hacking through hands-on challenges, labs, and real-world scenarios.

## Features

✅ **Interactive Web Interface** - Modern, dark-themed dashboard
✅ **Real Challenges** - Actual security vulnerabilities to practice on
✅ **Multiple Difficulty Levels** - Beginner to Advanced
✅ **Python Tools** - Real penetration testing utilities
✅ **Scoring System** - Track your progress and compete on leaderboard
✅ **Educational Content** - Learn security concepts with labs

## Tech Stack

- **Backend**: Node.js + Express
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Tools**: Python 3
- **Database**: Ready for MongoDB/PostgreSQL

## Installation

```bash
# Clone the repository
git clone https://github.com/abaletkhasebe-cpu/ethical-hacking-lab.git
cd ethical-hacking-lab

# Install dependencies
npm install

# Start the server
npm start
```

The application will run on `http://localhost:3000`

## Usage

1. Open your browser and navigate to `http://localhost:3000`
2. Browse available challenges
3. Click on a challenge to view details
4. Complete the challenge and submit your flag
5. Check the leaderboard for rankings

## Python Tools Included

- **sql_injection_tool.py** - SQL Injection vulnerability scanner
- **password_cracker.py** - Hash cracking utilities
- **network_sniffer.py** - Packet analysis tool
- **port_scanner.py** - Network reconnaissance

## Challenge Categories

### Beginner
- SQL Injection Basics
- Password Security

### Intermediate
- Password Cracking
- Network Sniffing

### Advanced
- Cross-Site Scripting (XSS)
- Authentication Bypass

## Learning Path

1. Start with SQL Injection basics
2. Move to password security
3. Progress to network analysis
4. Master advanced vulnerabilities

## Important: Ethical Use

⚠️ **This lab is for AUTHORIZED, LEGAL testing ONLY:**
- Only test systems you own or have permission to test
- Never use these tools on systems without explicit authorization
- Unauthorized access to computer systems is illegal
- Always follow local laws and regulations

## Security Best Practices

- Always use in isolated environments
- Never test on production systems
- Get written permission before testing any system
- Document all findings responsibly
- Report vulnerabilities through proper channels
